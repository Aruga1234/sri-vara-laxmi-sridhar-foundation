# Sri Vara Laxmi Sridhar Foundation Website

Static responsive website built with:
- HTML5
- CSS3
- Bootstrap 5.3
- Bootstrap Icons
- Vanilla JavaScript

## Run locally
Open `index.html` in a browser, or use VS Code Live Server.

## Deploy
Upload the complete folder to GitHub and connect the repository to Vercel, or deploy the folder as a static site.
